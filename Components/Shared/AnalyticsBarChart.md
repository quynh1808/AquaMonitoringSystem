# AnalyticsBarChart

Biểu đồ thanh CSS nhẹ, không phụ thuộc thư viện JavaScript.

- `Points`: chuỗi `DashboardSeriesPoint`.
- `ShowSecondary`: hiển thị thanh phụ, hiện dùng cho cảnh báo warning/critical.
- `Digits`, `Unit`: định dạng giá trị.

Phù hợp cho Dashboard Server vì không cần khởi tạo chart bằng JS sau mỗi lần render.
