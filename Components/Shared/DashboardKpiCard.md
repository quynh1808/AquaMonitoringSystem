# DashboardKpiCard

Card KPI có thể nhấn để chuyển sang trang phân tích tương ứng.

## Tham số

- `Label`: tên KPI.
- `Value`, `Unit`: giá trị chính.
- `Detail`: thông tin giải thích ngắn.
- `Meta`: trạng thái hoặc giá trị phụ.
- `Tone`: `blue`, `green`, `amber`, `red`, `violet`, `cyan`.
- `Href`: URL trang phân tích.

Component chỉ trình bày dữ liệu; toàn bộ phép tính nằm trong `DashboardAnalyticsService`.
